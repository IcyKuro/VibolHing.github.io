★ Haven Stack · Startup

Bricksy est une plateforme e-commerce développée par Haven Stack, une startup née dans le cadre universitaire et poursuivie au-delà. Elle permet aux utilisateurs de transformer une image en tableaux LEGO personnalisés, de les configurer et de les acheter directement en ligne.

Le site intègre un parcours marchand complet - gestion de panier, commandes, paiement, livraison - ainsi qu'une logique de stock pensée en lien avec une usine de fabrication de pièces LEGO. L'architecture repose sur un pipeline multi-langages PHP → Java → C pour le traitement automatisé des images.

Dans la continuité du projet, Haven Stack développe une plateforme de mini-jeux permettant d'obtenir des coupons de réduction, ainsi qu'une application mobile interconnectée au e-commerce.

Pipeline de génération

De l'image
au tableau LEGO

01
Web / PHP
Upload & sélection
L'utilisateur uploade son image et choisit ses dimensions de redimensionnement.
02
Java - JAR
Abaissement de résolution
PHP appelle le composant Java via ProcessBuilder. Le JAR applique des méthodes d'interpolation pour réduire la résolution.
03
C - Binaire
Calcul des 4 pavages
Le composant Java appelle le binaire C qui calcule 4 mosaïques selon différents critères (prix min, marge d'erreur…).
04
PHP / MariaDB
Sélection & panier
Les 4 pavages sont présentés avec leurs prix. L'utilisateur sélectionne, ajoute au panier et passe commande.
